Set up the project

Install Node.js 20.9 or newer and npm. Open a terminal in the geex-next folder, alongside package.json, and run:

npm ci
npm run dev

Open localhost:3000 for the dashboard or localhost:3000/landing for the Next.js showcase. The standalone showcase can also be opened from landing/index.html.

Dashboard demos

Use these paths on your local development server or open the live previews.

  • Default /
  • Banking /index-2
  • Crypto /index-3
  • Invoicing /index-4

Customize the template

Use the dashboard customizer to preview light and dark themes, LTR and RTL layouts, and sidebar or top navigation.

src/app/
Edit pages and layouts. Parenthesized route group names are omitted from URLs.
src/components/
Edit shared headers, sidebars, the theme customizer, and demo forms.
src/data/blog-posts.ts
Edit blog listings and articles. Give each post a unique slug for its detail page.
public/assets/css/style.css
Edit dashboard styles and component rules.
public/landing-assets/scss/style.css
Edit the styles for the Next.js showcase at /landing.
public/assets/js/main.js
Adjust widget initialization, chart series, and sample calendar events.

How demo data works

  • Tasks, contacts, calendar events, and blog comments are stored in the current browser. Clear site data to reset them. If the preview blocks browser storage, entries last for that preview session.
  • Chat messages last for the current page session.
  • Sign-in, registration, password reset, and verification demonstrate form behavior. Connect an authentication provider for production accounts.
  • Dashboard charts, invoice cards, and file lists use sample data.

Build and deploy

Run the lint check, create a production build, and start it locally for a final review.

npm run lint
npm run build
npm start

Deploy to a host that supports the Next.js App Router and serve the site over HTTPS. Update the demo URLs in landing/index.html if you change the deployed domain.

Third-party credits

Dashboard libraries include Bootstrap, jQuery, jQuery UI, Swiper, ApexCharts, FullCalendar, Dragula, and Nice Select 2. The showcase uses GSAP, SplitType, and Font Awesome. The project also uses Unicons and the Jost, Manrope, and Rubik fonts.

Template artwork and sample images come from the Geex source assets. Review their redistribution terms before packaging the template for distribution.
